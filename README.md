# RJW 中文化

RJW 與部分附加模組的中文化。<br />
目標是提供 RJW 與附加模組之間翻譯風格的一致性，以及與官方社群繁體中文用詞盡可能貼近的翻譯。

### 支援模組

可能有翻譯錯誤、詞不達意或用詞不一致的情況，若有問題請提出。<br />
